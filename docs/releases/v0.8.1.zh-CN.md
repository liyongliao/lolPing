# lolPing v0.8.1

修复 Windows 轮盘在切换窗口、显示桌面或截图之后被其他软件遮住的问题，并移除体验不稳定的滚动截图。

- 打开轮盘、显示标记或表情时重新恢复原生置顶层级，不抢走当前应用的输入焦点。
- 按住轮盘期间恢复被其他窗口覆盖的层级；松开后停止检查，不在空闲时持续调整窗口。
- 截图期间暂停轮盘置顶恢复与房间标记显示，截图完成或取消后恢复。
- 移除滚动截图工具栏按钮、滚动采集及拼接流程；保留快速框选复制、标注和一键离线 OCR。
- 原版轮盘、美术、音效和快捷动作设置保持兼容。

下载：Windows 使用 `lolPing-Setup-0.8.1.exe`；Apple Silicon Mac 使用 `lolPing-0.8.1-arm64.dmg`。

安装包由 GitHub Actions 构建并测试，附 SHA256SUMS.txt 与 BUILD-INFO.txt。置顶修复针对普通桌面应用及系统窗口切换；不覆盖 Windows 安全桌面或独占全屏的系统限制。
