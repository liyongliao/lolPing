# lolPing v0.8.0 · 一键截图工具栏

保留原版轮盘、表情、美术、音效与左右键配置，支持 macOS Apple Silicon 和 Windows x64。

- **一键提取文字 / 滚动截图**：直接放在框选后的高级工具栏；移除「完成后」下拉框。绿色「完成」直接复制图片。
- **更快的唤起**：移除统一 450 毫秒等待，启动时预热窗口状态服务；系统确认隐藏后立即采集。Mac 隐藏前清除自身窗口的可见内容，Windows 等待 DWM 提交窗口变化；保留图片解码完成后显示的检查。
- **真实页面滚动**：进入滚动模式后，直接在原页面内用滚轮或触控板向下滚动，工具停稳后拼接。工具栏持续可见，手动模式不移动鼠标。可点击「自动滚动」，并随时切回手动。
- **干净的长图**：优先直接采集选中的应用窗口，悬浮工具栏不进入图片；识别常见固定页头、页脚并保留一次。
- **完成即复制**：点击「完成并复制」、Esc 或再次按截图快捷键完成；自动模式到底后复制。匹配失败会保留已完成部分。
- **文字识别使用原始选区**：离线中文 / 英文识别，不上传截图。

操作：高级截图 → 框选 → 直接点击「提取文字」或「滚动截图」。滚动模式中可直接操作真实页面。

[使用说明](https://github.com/liyongliao/lolPing/blob/main/docs/quick-actions.zh-CN.md)。安装包由 GitHub Actions 构建，随包提供校验文件和构建来源。
