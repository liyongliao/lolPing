# lolPing v0.7.0 · 自动滚动截图

保留原版轮盘、表情、美术与音效，继续支持 macOS Apple Silicon 和 Windows x64。

- **自动滚动长图**：框选滚动内容后自动向下滚动并匹配拼接；到底后直接复制到系统剪贴板。
- **随时停止**：面板「停止并复制」、Esc 或再次按截图快捷键均可停止，正在采集时也有效。支持暂停、继续和取消。
- **修正采集时机**：先隐藏 lolPing 窗口并等待动画稳定，再采集；图片及编辑器加载完成后显示框选界面。
- **Mac 启动授权**：启动时检查屏幕录制和辅助功能权限，缺失时在设置窗口前方提示授权。设置页提供权限入口。
- **清楚的标注工具栏**：修复被拦截的图标字体，增加中文工具标签、清晰的深色图标和绿色完成按钮。
- 默认快速截图、离线文字识别、左右键同步设置与最近几次执行记录保持可用。

使用方法：高级截图 →「完成后」选择「开始滚动截图」→ 框选正文区域 → 绿色「完成」。请避开固定标题、悬浮工具栏与动画；匹配失败会暂停并保留已完成部分。

Mac 缺少权限时，请按启动提示开启权限，并按系统要求重新打开应用。滚动截图需要辅助功能权限。

[详细说明](https://github.com/liyongliao/lolPing/blob/main/docs/quick-actions.zh-CN.md)。安装包来自 GitHub Actions，随包附 SHA-256 校验文件与构建来源。

验证：Windows 安装后 15 项桌面测试通过；Mac 打包后 12 项适用桌面测试通过（跳过 3 项 Windows 专用测试）。两端均验证真实目标窗口自动滚动、长图尺寸、系统剪贴板、采集中停止、标注与离线识别。[GitHub Actions 构建与测试](https://github.com/liyongliao/lolPing/actions/runs/38398022690)。
