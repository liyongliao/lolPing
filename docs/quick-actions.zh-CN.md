# lolPing 快捷增强版 · v0.8.1

基于 [darrenprx/lolPing](https://github.com/darrenprx/lolPing) v0.5.1（来源提交 `f24a51e5a11c2b31dab72d89a571cc4025ad3c98`），保留原轮盘、表情、美术、动画、房间和音效。支持 macOS Apple Silicon 与 Windows x64。

## 下载与权限

[最新 GitHub Release](https://github.com/liyongliao/lolPing/releases/latest) 提供 Mac DMG、Windows 安装 EXE、SHA-256 校验文件与构建来源。安装包由 GitHub Actions 构建，Windows 工作流会先安装 EXE，再测试实际安装目录中的程序；Mac 工作流检查签名并测试打包后的应用。

Mac 启动时检查辅助功能与屏幕录制权限，缺失时在设置窗口前方显示授权提示；设置页也提供授权入口。辅助功能用于轮盘与鼠标标记，屏幕录制用于截图。按系统要求授权并重新打开应用。开发构建与安装版本属于不同应用身份，请授权实际使用的 lolPing。

## 连续信号快捷动作

在「快捷动作」中编辑或添加规则，设置名称、信号、连续次数、相邻信号最大间隔、冷却时间和执行动作。默认三个模板均关闭，设置目标并开启后才执行。

- 动作支持：打开 Mac `.app` / Windows `.exe`、打开 http/https 网址、复制文本、区域或全屏截图。
- 最多 50 条规则；连续次数 1–10，相邻间隔 0.5–10 秒，冷却 1–60 秒。同一信号可设置多条规则。
- 每条规则可选左键、右键或左右键生效。左右键分别计数，同一规则共用冷却。
- 其他信号、表情、暂停和截图会中断连发计数；冷却期间不累计。设置改变会重新计数。
- 设置预览和房间成员发来的信号不触发本机快捷动作。

「最近执行记录」默认收起，仅显示最近 3 次，可改为 5 或 10 次；记录只在本次运行内保留。

## 左右键与房间同步

按住原版触发键（Mac Option / Windows Alt，或自定义触发键），左键或右键拖动即可使用原版信号轮盘。普通右键菜单照常使用；左键轮盘打开时，右键仍取消。侧键触发沿用原版手势。

加入房间后默认左右键标记都同步。可在「房间」中改为仅左键同步、仅右键同步或都不同步。未同步的标记仍在本机显示，不会影响其他成员；接收成员标记的静音设置独立控制。快捷规则的鼠标键配置与房间同步配置相互独立。

## 截图

默认快捷键为 Mac `⌘⇧2` / Windows `Ctrl+Shift+2`；设置中可修改，留空关闭。快捷键冲突会保留原设置，不能与暂停键相同。截图不依赖轮盘或快捷规则开启。

截图前隐藏 lolPing 窗口，在系统确认窗口已隐藏后立即采集鼠标所在显示器，不再统一等待 450 毫秒。Mac 在隐藏前使自身窗口不可见，窗口状态服务在启动时预热并复用；Windows 等待 DWM 提交窗口变化。图片解码及编辑器准备完成后才显示框选界面。结束后恢复窗口。

### 快速截图（默认）

拖动框选，松开即复制原始清晰度图片；Esc 或右键取消。默认不启用标注、文字识别或文件保存。轻量框选窗口在启动时预加载，预加载本身不读取屏幕。

全屏截图直接复制整个显示器。可选「截图同时保存为 PNG」，文件位于系统图片目录的 `lolPing` 文件夹。

### 高级截图

在设置中选择默认高级模式，或单次点击「高级截图」。框选后，工具栏有图标和中文名称，「提取文字」直接位于框选后的工具栏，点击就执行。绿色「完成」直接复制标注后的图片。

- **标注图片**：矩形、椭圆、箭头、画笔、文字、马赛克、撤销和重做。完成后直接复制。
- **提取文字**：点击工具栏即从原始清晰度选区提取并复制。随包提供简体中文和英文模型，Tesseract.js 离线识别，不上传截图。只有使用时才初始化识别线程，首次需要数秒。

v0.8.1 已移除体验不稳定的滚动截图入口、后台采集和自动拼接。

## 构建与验证

推荐 Node.js 22。安装依赖并构建当前平台的原生输入 helper：

```sh
npm ci
npm run test:helper
npm run typecheck
npm test
npx install-electron
npm run test:e2e
```

Mac Apple Silicon：`npm run dist:mac`，产物 `release/lolPing-0.8.1-arm64.dmg`。
Windows x64（在 Windows 上执行）：`npm run dist`，产物 `release/lolPing-Setup-0.8.1.exe`。

推送 main / codex/* 分支会触发 CI，也可在 Actions → CI → Run workflow 运行。桌面测试覆盖规则与持久化、原轮盘左右键、快捷应用、截图时机、标注工具栏、离线识别、Windows 原生置顶恢复、前台焦点、显示桌面后轮盘、剪贴板及双客户端房间同步。Windows 原生窗口层级测试只在 Windows 上执行，Mac 环境明确跳过。
